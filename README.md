# Bahria University — Computer Science Department

A modern and responsive Computer Science Department website designed to present academic programs, faculty information, and university contact details through a clean and professional interface.

## Overview

This project is a frontend implementation of a university Computer Science Department website. It focuses on creating a structured, responsive, and user-friendly interface using modern frontend technologies.

The layout includes a university hero section, academic programs, faculty profiles, and a contact section with a responsive navigation system.

## Features

- Responsive and sticky navigation bar
- University hero/banner section
- Academic programs showcase
- Faculty profile cards
- Contact information section
- Responsive contact form
- Font Awesome icons
- Bootstrap responsive grid system
- Hover effects and smooth scrolling
- Mobile, tablet, and desktop support

## Tech Stack

| Technology | Purpose |
|------------|---------|
| HTML5 | Website structure |
| CSS3 | Styling and custom UI |
| Bootstrap 5 | Responsive layout and components |
| Font Awesome | Interface icons |

## Website Sections

### Home
Introduces the Computer Science Department with a university campus hero section and call-to-action button.

### Programs
Displays the department's academic programs:

- BS Computer Science
- BS Artificial Intelligence
- BS Software Engineering

### Faculty
Presents faculty members with their:

- Profile
- Designation
- Area of specialization
- Social media links

### Contact
Provides university contact information along with a contact form for user inquiries.

## Responsive Design

The website is optimized for:

- Desktop
- Laptop
- Tablet
- Mobile devices

Bootstrap's responsive grid system is combined with custom CSS media queries to maintain a consistent layout across different screen sizes.
